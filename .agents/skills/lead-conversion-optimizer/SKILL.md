# Lead & Conversion Rate Optimizer (CRO)

This skill optimizes forms, onboarding funnels, micro-copy, and value propositions for the Feng Shui web application.

## Funnel Stages & Optimization Rules
1. **Intake / Step-by-step Flow**:
   - Progressive disclosure: 1-2 questions per screen to minimize cognitive load.
   - Low-friction initial step: Start with easy choices (typ przestrzeni: mieszkanie / dom / biuro) before requesting file upload or contact info.
   - Micro-reassurance: Display privacy note ("Twój rzut jest przetwarzany bezpiecznie i poufnie") near upload fields.

2. **Call to Action (CTA) Standards**:
   - Use outcome-driven verbs: "Wygeneruj bezpłatny plan harmonii", "Rozpocznij audyt przestrzeni".
   - Avoid generic "Wyślij", "Kliknij tutaj", "Submit".
   - Place social proof / methodology signals directly below key action buttons.

3. **Value Ladder & Monetization**:
   - Free / Instant preview -> Structured self-audit PDF -> Full 1-on-1 expert consultation booking.
