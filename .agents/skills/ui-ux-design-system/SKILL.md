# Premium UI/UX Design Framework

This skill elevates website design to luxury, editorial-grade standards.

## 1. Aesthetic Philosophy: "Less, but significantly better"
- **Zero generic AI template look**: Avoid purple/violet on dark, neon glowing borders, icon-stuffed bento boxes, pill badges with pulsing dots, and rainbow gradient text.
- **Harmonious Warm Palettes**: Tailored HSL color tokens (warm stone, sage green, sand ochre, deep charcoal) reflecting wellness and architectural calm.
- **Surface Depth & Texture**: Layered elevation with subtle box-shadows, soft borders (`1px solid hsla(...)`), and tactile card backgrounds.

## 2. Typography & Hierarchy (Editorial Excellence)
- **Scale**: Modular ratio (1.25 / 1.333).
- **Tracking & Kerning**: Tight letter-spacing for large headlines (`-0.02em` to `-0.03em`), generous line-height for body text (`1.6` to `1.75`).
- **Contrast & Legibility**: Strict WCAG AA/AAA compliance for text readability on all backgrounds.

## 3. Micro-Interactions & Motion
- **State transitions**: Smooth `cubic-bezier(0.16, 1, 0.3, 1)` easing (180ms - 250ms) for button hovers, card lifts, and focus rings.
- **Feedback**: Obvious active, disabled, loading, and error states on every interactive element.
